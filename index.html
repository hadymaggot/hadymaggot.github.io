Sapto Hadi (Ahadizapto): Security, Operations, dan Software Engineer

Saya Sapto Hadi (Ahadizapto), software engineer di bidang security dan operations. Aplikasi web saya kembangkan dengan PHP/Laravel, Vue, dan Python. Di sisi operations, pekerjaan saya meliputi container dan Kubernetes, infrastructure as code, CI/CD, serta monitoring. Pengujian keamanan mencakup access control, kebocoran data di sisi client, header dan TLS, serta dependency yang memiliki CVE. Di bidang GIS, pekerjaan saya mencakup pengolahan data spasial (GeoJSON, shapefile, PostGIS) dan aplikasi peta interaktif dengan MapLibre, Leaflet, dan OpenLayers.
